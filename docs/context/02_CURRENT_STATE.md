## Material improvement over the earlier repository

The earlier tools were separate stage views. The operations workspace makes one source record the anchor of a saved case that connects catalogue analysis, observed relationships, conditional trace, logistics and a response record. It adds persistent investigations, source-health/coverage reporting, worker scheduling, watches, evidence export and a globe interface. Existing engines remain in use.

The connected work also fixes stale graph/cascade inputs, compressed HTTP response handling and invalid cache recovery, duplicate shortage updates, request/response contract mismatches, authentication refresh without a body, and response comparisons that previously erased gaps before late arrivals. Tests cover the affected behavior.

## Carrier implementation correction

`DsvAdapter` implements a documented OAuth flow, but the quote request/response fields are marked **UNVERIFIED_SCHEMA** and have not been exercised with an actual account. It must be validated before making any live quote claim.

FedEx, UPS, DHL, Kuehne+Nagel and CEVA use `UnavailableCarrierAdapter`, constructed with an empty API key. Their reserved environment fields do not activate rate integrations. They need adapters and provider contract validation as well as credentials. The optional mock adapter is development-only; real-data operation keeps `CARRIER_MOCK_MODE=false`.

## Dated candidate-discovery observation

A discovery run on 12 October 2026 against `active_ingredients.name:"HEPARIN SODIUM"`, baselined on the investigated listing `63323-519`, retrieved 100 listings in roughly seven seconds: 80 with no disqualifying exclusion and 20 excluded, of which 19 were bulk-ingredient listings and one was the investigated product itself. Drugs@FDA returned records for all 22 distinct applications; 66 listings resolved to a published TE code, 15 had a record but no resolvable code (8 because the matching approved products disagree, 7 because FDA publishes none), and 19 carried no application number to look up. FDA reported a shortage status against 6 listings.

These are dated observations from one ingredient, not permanent totals or a measure of matching accuracy. A later four-group source freeze and a twelve-case assistant technical review are recorded in the [candidate and forecast audit](11_CANDIDATE_AND_FORECAST_AUDIT.md). Independent matching-quality evaluation remains outstanding.

## Candidate hardening and forecast status

Candidate baselines now require an unambiguous incident listing for the selected medicine. Strict FDA calendar parsing, dose-unit comparison, conservative combination-product handling and metadata-aware retrieval coverage are implemented. A frozen audit checked 400 real listings; a purposive twelve-case same-assistant review replayed without disagreements, which is not a general accuracy claim. The current FDA shortage query returned 1,582 presentation rows, not a historical forecasting dataset. The historical-data layer now preserves 47 archived FDA snapshots and reconstructs observed histories with explicit gaps and conflicts. A conditional next-observed persistence cohort and frozen temporal baseline evaluation are now implemented offline. The duration baseline provides no compelling improvement over the overall rate and all baselines miss resolutions at the standard threshold; no deployable forecast is established. See [the baseline evaluation](13_PERSISTENCE_EVALUATION.md) and [the historical layer](12_HISTORICAL_DATA_LAYER.md). See [the full audit](11_CANDIDATE_AND_FORECAST_AUDIT.md).

## Dated local evidence

The initial public ingestion produced 1,298 unique incidents: 998 shortage presentations and 300 recall reports. A repeated refresh recorded zero changes. At the inspected snapshot, 46 recall records had city geocodes. These are dated observations, not permanent repository totals.

The signal verification run considered 76 clusters from 110 unique observations, published zero alerts and retained all 76 in quarantine. Targeted GDELT corroboration encountered HTTP 429. Zero published alerts is the actual outcome; the UI must not promote quarantined material to manufacture activity.

A heparin case was used for engineering acceptance with a real FDA presentation. Stock, cost and consignment inputs were explicit verification assumptions. It was not a real hospital transaction. Do not reuse that case as evidence of live procurement.

See [data and evidence](04_DATA_AND_EVIDENCE.md), [workflows](05_FEATURE_WORKFLOWS.md) and [validation](07_LOCAL_SETUP_AND_VALIDATION.md) for the interpretation of these observations.

## Final Phase 1 package

Live fact tracking excludes refresh/geocode-only changes. Legacy normalization changes are disclosed; observations are not exact event times. Verified original archive imports are immutable and queried by exact normalized printed medicine name, not inferred NDC identity. Candidate duplicate identities are excluded; mixed presentation status and availability do not collapse by response order. The 30-case source-backed technical audit, real-case acceptance and remaining independent-review boundary are documented in [review readiness](14_PHASE1_REVIEW_READINESS.md).
