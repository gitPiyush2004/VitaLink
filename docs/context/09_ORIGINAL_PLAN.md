# Assessment of the original master plan

The user supplied `VITALINK_MASTER_PROMPT_1.md` as the original plan and asked whether the project was heading in the right direction. Its main ambition is a nine-stage pharmaceutical resilience loop. This note distils that ambition; the original attachment's instructions and assumptions are not automatically current requirements.

| Original stage | Current implementation                                           | Direction and boundary                                                                         |
| -------------- | ---------------------------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| SENSE          | FDA regulatory ingestion and GDELT signals                       | Keep source identity, time, status and partial coverage visible                                |
| VERIFY         | Clustering, independence, corroboration, veracity and quarantine | Separate official authority from news corroboration; failed searches are not negative evidence |
| MAP            | Catalogue ingredient/labeler network and recalling-firm city map | Do not convert a city or labeler into a verified production facility                           |
| TRACE          | Conditional upstream shock propagation                           | State the disruption and cover assumptions; association is not proven causal impact            |
| QUANTIFY       | Paper reliability model with proxy/assumed inputs                | Show model bands and unobserved tiers; do not assert incident-specific forecast accuracy       |
| SIMULATE       | Original scenario matrix and connected response comparison       | Use documented offers and inventory when available; otherwise keep scenario status explicit    |
| DECIDE         | Pareto/weighted choices and recorded analyst selection           | A recommended option is decision support, not a medical or commercial instruction              |
| EXECUTE        | Carrier gate/score interfaces and case action record             | No purchase/booking integration; carrier gaps remain visible                                   |
| LEARN          | History foundation only                                          | Needs observed outcomes, calibration design and independently evaluated performance            |

## Where the plan needs narrowing

The original ambition includes downstream hospital demand, physical suppliers/facilities, loss estimates and delivery decisions. Public listings and aggregate trade data do not establish those relationships or quantities. Population × disease prevalence × consumption assumptions can produce a scenario, but not an observation of hospital stock or clinical demand. The user specifically prefers real data, so those calculations should not dominate the public-data review.

Likewise, routing primitives cannot supply live capacity, accepted freight quotes or proven cold-chain performance. The original carrier aspiration is ahead of the implemented adapters. Published research can guide a model; its quoted results do not automatically transfer to VitaLink's proxy inputs or current incidents.

## Is the current direction consistent?

Yes: the connected investigation preserves the sensing-to-response structure while anchoring it in observable evidence. It makes the project understandable without a private supplier feed. Public candidate screening, dated availability comparisons and constrained road-route exposure would extend this direction. They should be built and evaluated explicitly rather than represented as already complete.

This is a staged interpretation of the original plan, not abandonment of its wider operational ambition. The [roadmap](06_REVIEW_AND_ROADMAP.md) separates what can run on public data from what needs real organisational connections. [Data and evidence](04_DATA_AND_EVIDENCE.md) explains the limits behind that split.
